# react-ts-form
React with Typescripts using framer motion, formik and yup for form validation.

## Development

Install the project dependencies and start the Vite dev server:

```bash
npm install
npm run dev
```

Running `npm run dev` without installing dependencies results in the error `vite: not found` because the local binaries are missing.

If you see an `http-proxy` warning during installation, unset any proxy‑related environment variables before running `npm install`:

```bash
unset http_proxy https_proxy
```
